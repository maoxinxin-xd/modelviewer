# 3D 模型查看器

原生 TypeScript + HTML + CSS + Three.js 实现的独立 3D 模型查看器，完整复刻 mivo-web 中「3D 模型 - 打开查看器」弹窗的 UI 与交互，并做了如下调整：

- 支持更多格式：GLB / GLTF / OBJ / FBX / STL / PLY / DAE / 3MF
- 底部新增「导入」按钮，本地选择模型文件即可预览
- 左侧去掉 6 格截图 UI
- 「截屏」直接下载 PNG 图片（1:1 正方形，透明背景）
- 「导出」下载当前已导入的模型源文件

## 启动

```bash
cd modelViewer
npm install
npm run dev
```

打开终端提示的本地地址（默认 `http://localhost:5174`）。

## 构建

```bash
npm run build
npm run preview
```

## 功能清单

| 区域 | 功能 |
|------|------|
| 画布 | 轨道旋转 / 缩放 / 平移，背景渐变与原弹窗一致 |
| 左侧 | 模型信息：文件名、拓扑、面数（无截图九宫格） |
| 右侧-显示设置 | 透视 / 正交切换；正视 / 背视 / 侧视 / 俯视 |
| 右侧-灯光设置 | 角度圆盘拖拽、射灯强度、平面光强度 |
| 底部 | 贴图 / 白膜 / 法线 / 反照；收藏；截屏下载；导入；导出 |

## 说明

- 相机、灯光、材质切换均基于 Three.js 场景直接实现，不再依赖 `@google/model-viewer`。
- 截屏会临时隐藏地面网格，再输出 1:1 透明底 PNG 并触发浏览器下载。
